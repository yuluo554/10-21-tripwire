| R7 | 发布附件口径漂移（本机生成 vs CI 生成） | 校验和不可复核 | `SHA256SUMS` 只由 CI 生成；补传只用 `gh run download` 的字节 |
| R8 | 版本号两处手抄漂移 | 报告版本与实际不符 | `pyproject` 用 `dynamic = ["version"]` 读 `__init__.__version__`；测试断言 `--version` == `__version__` |
| R9 | 计划文档点名了不存在的工具/脚本 | 文档承诺落空 | 布局门 `LAYOUT.DOC_TOOLS`：扫描 `plan/` 与 `AGENTS.md` 里的 `tools/*` 路径并逐个断言存在 |

> 全量决策记录在 `plan/00` §二；此处只登记与**交付形状**相关的决策（M0 起逐棒追加）。

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-10-21 | **D11·计划套件在 M0 一次落全（00–06）** | 避免"M1 开工前才写 02"导致的返工；M0 的 DoD 因此包含"布局门全绿" |
| 2026-10-21 | **D12·版本号单一来源 = `__init__.__version__`，`pyproject` 用 dynamic** | 手抄两处必漏改（SKILL 阶段 7 C 节）；Python 侧用 dynamic 版本是最省事的"单一来源"落法 |
| 2026-10-21 | **D13·骨架期未实现子命令统一 exit 3，不伪造空结果** | 退出码 3 = 用法/拒绝运行；"阶段未就绪"属于用法通道，不得冒充 0（无损） |
| 2026-10-21 | **D14·`rules.json` 只存谓词函数名，不内嵌表达式** | 避免"规则即代码"的沙箱与注入问题；谓词是纯函数，可被 AST 守门检查 |
| 2026-10-21 | **D15·`plan/06` 缺口表关闭时不点名文件** | 布局门 `LAYOUT.GAPS` 会命中文件名里的里程碑号（假门族 ⑥⑧）；只描述不指路 |
| 2026-10-21 | **D19·判定出口 M5 起三条并列（`run --expected` / `report` / `gate`），无真值仍 exit 3** | 首屏第三段就是门禁三数；`run` 不给真值就只跑管线并拒绝判定。三条出口都调 `compute_gate`，不是放宽 D18 |
| 2026-10-21 | **D20·`LOSSLESS` ⇒ `Gate.vacuous`；报告必须把"空跑"写清楚** | 真值只登记"会变的格"，所以无损必然对应"本阶段 0 条期望"；不写清楚就会被读成"覆盖了样本" |
