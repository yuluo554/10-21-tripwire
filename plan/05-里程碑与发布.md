## 五、发布计划（M6）

1. **tag 前**：`plan/RELEASE-M6.md` 写好（§一 tag 前事实 / §二 tag 后追加 / §三 阶段 7 覆盖对账）并**进 tag 树**。
2. **tag 前**：`python -m build` 产 sdist + wheel；`SHA256SUMS` 由 CI 生成（不是本机）。
3. **tag**：`v0.1.0`（annotated），打在做完定版的提交上。
4. **Release**：附 sdist + wheel + `SHA256SUMS`；正文登记 digest。
5. **tag 后**：只允许非交付面提交（`plan/`、`README.md`、`tools/`、`tests/`）；交付面（`src/`、`rules.json`、`pipelines/`、`fixtures/`）**零差异**。
6. **复核**：真下载 + 中立目录 + `sha256sum -c` + 从 tag 重建**内容级**对账（sdist 成员内容全等；**字节级不等**——setuptools 嵌 mtime，见 D26）。

> **自指约束**：tag 树内的留档**不写** tag OID / commit sha / 附件 sha256 的字面值——写进 tag 树就立刻失效。字面值写在 tag 之后的 `plan/` 提交或 Release 正文里。
